# Танаис — Vue 3 проект

## Запуск
1. Установи Node.js (LTS).
2. Открой папку проекта в VS Code.
3. В терминале выполни:
   ```bash
   npm install
   npm run dev
   ```
4. Открой адрес, который покажет Vite (обычно http://localhost:5173).

## Страницы
- `/` — Главная
- `/expeditions` — Экспедиции
- `/expedition/tanais` — Танаис. По следам античности

Кнопка «Войти» в шапке открывает модальное окно. Закрывается крестиком или кликом по затемнённому фону.
Форма демонстрационная: серверная авторизация не подключена.

## Технологии
Vue 3, Vite, Vue Router, JavaScript, CSS.
